# Superstore Sales Exploratory Data Analysis (EDA) 📊

A comprehensive Exploratory Data Analysis project built using Python to analyze retail sales performance, customer trends, and geographic profitability for a Superstore dataset.

## 🚀 Project Overview
This project aims to extract actionable business insights from 9,800+ transactions. By cleaning raw data, analyzing category performance, and visualizing multi-year seasonal sales trends, this project provides data-driven strategies for inventory management and regional marketing.

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** VS Code, Jupyter Notebooks (`.ipynb`)

## 🔑 Key Insights & Findings
1. **Top Product Category:** **Technology** generates the highest overall sales revenue (~$827K), followed by Furniture and Office Supplies.
2. **Geographic Concentration:** **California** and **New York** are the top-performing states, contributing the majority of the total revenue.
3. **Seasonal Trends:** Time-series analysis revealed predictable, sharp sales spikes during the final months (November–December) of every year, aligning with holiday/festive shopping behavior.

## 📈 Visualizations Included
* Category-wise Total Sales Bar Chart
* Top 5 States Revenue Distribution
* Monthly Sales Trend Over Time (Time-Series Line Chart)
* Numerical Correlation Heatmap

## 💻 How to Run the Code
1. Clone this repository to your local machine.
2. Install the required dependencies: `pip install pandas numpy matplotlib seaborn`
3. Open `sales_eda.ipynb` in VS Code or Jupyter Notebook and run the cells.
